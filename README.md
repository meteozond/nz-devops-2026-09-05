# Ansible — meetup part 2

Each team has its **own self-contained folder** `teamN/` with its own ansible.
Terraform (`../tf`) generates the `hosts` inventory on `apply`; everything else
is committed as regular files:

```
teamN/
  .devcontainer/devcontainer.json  # image alpine/ansible; installs netaddr, kubectl, k9s, nano, vim on create
  ansible.cfg                       # inventory = hosts, remote_user = root
  hosts                             # generated by terraform; FQDN entries in masters/workers/k8s_cluster
  update_known_hosts.yaml           # remove + re-add host keys (IP + DNS name) in ~/.ssh/known_hosts (run first)
  deploy_pubkey.yaml                # push a public key to root's authorized_keys
  deploy_rke2.yaml                  # RKE2 cluster on masters + workers (role lablabs.rke2)
  requirements.yml                  # galaxy role lablabs.rke2 + collection ansible.posix
```

The `hosts` inventory has **no password** — pass the SSH password on the CLI
(`-k` / `--ask-pass`, or `-e ansible_password=...`). Each team has one shared
root password for all 4 machines; get it from `terraform output` in `../tf`.

## Dev container

Open a team folder in its dev container (VS Code / `devcontainer` CLI). It uses
the `alpine/ansible` image and installs `netaddr`, `kubectl`, `k9s`, `nano` and
`vim` on create; the image already ships `sshpass` and `ansible.posix`, so no
extra host setup is needed.

## Host setup (without the dev container)

```bash
brew install sshpass                          # password login (macOS)
ansible-galaxy install -r requirements.yml    # role + collection
# netaddr (required by the rke2 role) — the dev container installs it automatically
```

## Usage (from your team folder)

```bash
cd 2/ansible/team3
ansible-playbook update_known_hosts.yaml               # run first: refresh host keys (no SSH to hosts)
ansible all -m ping -k                                 # connectivity check (-k prompts for the SSH password)
ansible-playbook deploy_pubkey.yaml -k                 # push ~/.ssh/id_ed25519.pub (override: -e pubkey_file=...)
ansible-playbook deploy_rke2.yaml                      # RKE2 cluster (key-based after deploy_pubkey; else add -k)
```

`teamN/hosts` is gitignored — it contains passwords.
